# Static Website Hosting using Amazon S3 and CloudFront

## 📘 Overview
This project demonstrates how to deploy a static website using an Amazon S3 bucket and accelerate global access using Amazon CloudFront.

## 🚀 What I Did
- Created an S3 bucket for website hosting  
- Enabled static website hosting  
- Uploaded HTML/CSS/JS files  
- Configured CloudFront distribution  
- Connected CloudFront to the S3 bucket  
- Improved performance using caching and CDN  

## 🧩 AWS Services Used
- Amazon S3  
- Amazon CloudFront  
- AWS Certificate Manager (Optional)  
- Amazon Route 53 (Optional)  

## 📂 Files to Include
- `/website-files` → All website HTML/CSS  
- `/docs/architecture.png` → Architecture diagram  
- Deployment notes or AWS CLI commands  

## 📝 How to Deploy
1. Create an S3 bucket  
2. Enable static website hosting  
3. Upload website files  
4. Create a CloudFront distribution  
5. Point domain (optional)  

## ✔ Key Learning
- Hosting static websites efficiently  
- Using CDN for global content delivery
